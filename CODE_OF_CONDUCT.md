# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its contributor code of conduct. That text defines the pledge, standards, scope, enforcement responsibilities and community impact guidelines; its attribution and CC BY 4.0 terms apply.

Be respectful, accept constructive feedback, protect private information and keep collaboration free of harassment. These expectations cover repository discussions, reviews and project spaces, including conduct while representing the project elsewhere.

Report concerns privately to the repository owner, [ocr1n](https://github.com/ocr1n), using an available private GitHub contact channel. If none is available, request a private contact method without posting allegations or personal information publicly. The owner is responsible for confidential review and fair enforcement under the adopted covenant. A separate project reporting address has not yet been established.
